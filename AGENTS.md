# Project conventions
Use Bun exclusively for installing dependencies and running scripts. Use `bun install`, `bun run dev`, and `bun run build`.
Keep the core presentation under 10 minutes, including transitions. Speaker notes are the verbatim spoken script. Stage cues must be clearly bracketed. Sources and technical backup belong in the appendix and SOURCES.md. Distinguish SpaceX announcements from our classroom proposal and illustrative assumptions.
